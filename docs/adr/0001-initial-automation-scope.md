# 首版接管固定配置下由用户手动开启的单场战斗

2026-10-14，用户确认：首版采用固定角色配置，自动完成用户手动开启的一场战斗。相比自动选场、连续刷场及装备购物养成一体化，这个边界减少需要同时实现和验证的决策场景，使工作集中在战斗决策与执行。

成本取舍以减少开发维护工作为先。用户最终确认每月 $5 只是费用提醒线，覆盖逐次决策与战后偏好归纳，不设置实际支出上限。超过提醒线仍继续模型调用和游玩，不因费用切换策略或停止记录。该决定取代此前“$5上限”的说法；继续保留用量和费用统计以便观察成本。

数据完整性优先于自动操作的连续性：记录写入失败或动作结果无法确认时暂停自动操作，先恢复记录与状态确认再继续。已经发生的缺口如实标记，不补猜成完整轨迹。

用户明确不预设“稳定通关优先”；后续确认从亲自游玩的记录中学习情境化偏好，详见 [ADR 0002](0002-learn-preferences-from-play-demonstrations.md)。本ADR不批准任何特定训练方案或奖励函数。
