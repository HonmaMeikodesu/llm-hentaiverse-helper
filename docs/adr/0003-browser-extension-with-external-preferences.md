# 在浏览器扩展中用已确认偏好辅助Jev决策

用户确认首版采用“录制示范 → 战后归纳偏好 → 用户校对 → Jev参考偏好选动作”。少量通用模型请求负责偏好归纳，Jev负责逐次动作选择，均计入同一费用统计。个性化来自外部保存的偏好与示范，首版不训练独立策略模型，不将此过程称为强化学习。相比立即建设策略训练与奖励优化流程，这条路线先验证能否正确理解玩家取舍，减少开发维护工作，并保留供未来研究使用的轨迹。

用户同时确认沿用浏览器扩展：打开HV页面即可录制或接管，完整记录保存在本机，仅把决策与归纳所需内容发送给模型；关闭游戏页面后停止游玩。相比扩展加独立本地服务或远程常驻程序，该方案复用现有工程并减少日常启动与部署负担。首版已通过独立Chromium加载真实扩展的测试，覆盖模拟接口下的录制、审阅、对照、接管及跨轮恢复；真实模型连接和当前游戏版本实战仍待验证，详见 [安装与验证说明](../../README.md)。

用户最终明确每月 $5 为提醒线，不设实际支出上限；达到提醒线不停止调用，也不需要为费用原因增加本地备用策略。记录功能独立于付费模型调用，模型故障也应保留已经观察到的游戏事实。记录写入失败或动作结果不明时，暂停自动操作并恢复，缺口如实标记。这些约束优先保证可追溯的轨迹，不预设游戏中的保守打法。
