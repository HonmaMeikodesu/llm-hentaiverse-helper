# Hentaiverse 策略助手

Chrome MV3 扩展：记录你的实际游玩，从示范中归纳有条件的打法偏好，经你审阅后，让 Jev 在当前可用的动作中选择。首版接管固定配置下、由你手动开启的一场战斗。

目前已实现录制、偏好归纳与审阅、对照回放、自动接管、本地轨迹和费用统计。真实 Jev / 百炼归纳接口已连通；真实扩展完成过2个无偏好 Jev 动作及战败后停止，费用约 $0.0006。这次战斗失败，个性化效果与跨轮完整实战尚未验证。详见 [实测记录](docs/research/hv-live-smoke-2026-10-14.md)。

## 安装

需要 Node.js 22+ 和 Chrome 111+。

```sh
npm ci
npm run build
```

打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选择本仓库根目录（含 `manifest.json`），然后刷新已打开的HV页面。扩展图标打开设置，游戏页面右下角显示录制与接管入口。重新构建后，在扩展管理页重新加载扩展并刷新游戏页面。

## 从你的游玩开始

1. **配置。** 设置中填写这批示范的装备流派、难度与能力说明。配置变化后重新保存，会创建新的配置标识，旧示范不会自动混入。填写 Jev Key，以及兼容 Chat Completions 的归纳接口、Key和模型。Key保存在扩展本机数据库中，不放在游戏页面或导出文件里；它不是加密密钥保险库。
2. **录制。** 保持配置一致，手动开启一场战斗，点击“录制 / 恢复录制”，照常用鼠标或快捷键游玩。自动识别战斗动作请求和响应；战斗结束后自动结束记录，也可手动结束。每次只允许一个标签页记录或接管。
3. **归纳。** 选择几场已结束、同配置的记录，点击“从所选示范归纳偏好”。系统只用可确认的人工操作；会覆盖整个批次抽样，最多60个局面，并限制输入长度。证据不足时可以少于3条，甚至不提出偏好。
4. **审阅。** 检查约3–5条偏好的适用条件、取舍、证据与反例，修改后勾选认可的条目，再保存。未勾选视为拒绝；没有确认偏好时不会开始接管。
5. **对照。** 可选一场没有参与当前偏好归纳的人工记录做对照回放。最多5个局面、每个局面两次Jev调用，展示未个性化与参考偏好/示范后的建议。不会执行游戏操作，也不能据此知道替代动作的真实后果。
6. **接管。** 手动开启战斗后点击“接管 / 恢复接管”。这场会话使用固定的配置及偏好版本。你在游戏区域的首次点击或按键会暂停接管；再操作即可手动继续。需要人工处理的游戏页面会暂停。

尚无偏好时，可使用独立的“无偏好测试（最多5步）”验证 Jev 连接、动作执行与记录。它不提供偏好或示范，最多执行5个已确认的模型动作后暂停；再次点恢复不会重置计数。结果不明或观察不完整仍会提前暂停。测试记录可查看和导出，但不能用于归纳或对照；正式录制/接管与测试之间切换需先结束当前记录。页面中也会显示模型 Key 是否已配置（不等于连接测试已通过）。

录制不需要模型Key。保存归纳接口设置时，Chrome会请求该域名的访问权限。默认归纳地址沿用原项目的DashScope兼容接口，但Key、模型可用性与实际计费需要你自己的账户配置。归纳价格留空时，token用量仍保存，金额标为待核对。

## 使用一个 Vercel AI Gateway Key

在 [Vercel AI Gateway 的 API Keys 页面](https://vercel.com/d?title=AI+Gateway+API+Keys&to=/%5Bteam%5D/~/ai-gateway/api-keys) 创建 Key，无需部署网站。扩展设置点击“使用 Vercel 配置两个模型”，在两个 Key 栏填写同一个 Gateway Key，再保存并授权网关域名。更新扩展代码后需要在 Chrome 扩展管理页重新加载。

- Jev 服务商：Vercel AI Gateway；模型 `typesafe-ai/jev`。
- 归纳接口：`https://ai-gateway.vercel.sh/v1/chat/completions`；预设模型 `google/gemini-3-flash`，效果仍需示范验证。
- Jev 走 [TypeSafe 兼容接口](https://vercel.com/docs/ai-gateway/sdks-and-apis/typesafe)，不能使用聊天接口。网关模型名称是别名，不等同于直连固定版本。
- 优先记录网关返回的费用；未返回时，归纳按所填单价估算，网关 Jev 金额记为待核对。归纳预设单价来自 [模型页面](https://vercel.com/ai-gateway/models/gemini-3-flash)：每百万输入 $0.50、输出 $3（2026-10-14）。

百炼 Token Plan 也可单独用于归纳，与 Vercel Jev 搭配。归纳接口填写完整地址 `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/chat/completions`，模型 `qwen3.8-flash`，归纳 Key 使用百炼专属 Key。不要把只到 `/v1` 的 base URL 直接填作完整接口。价格留空时保留 token 用量，金额待核对；不把套餐额度消耗记作免费。2026-10-14 已验证此组合的真实接口和归纳结果格式，尚未完成个性化自动实战。

## 记录与恢复

轨迹保存在扩展源的 IndexedDB，每个事件有会话ID与连续序号。它关联观察到的状态、可用动作、实际动作、人工/Jev来源和后续结果。鼠标与快捷键经游戏实际发出的请求统一记录；不保存游戏令牌、Cookie、完整页面脚本或原始网络请求体。

- 自动动作先持久化意图，确认当前状态仍匹配后才点击；响应确认并写入后才允许下一步。
- 写入失败、无法确认动作结果、未知页面结构或未归属的状态变化会暂停。数据缺口如实保存，不用模型补造。
- 同一页面中的未知动作不能直接重发。先刷新游戏页面核对状态，再点击恢复；重载会留下中断记录，旧动作不会自动重放。
- 正常跨轮推进会保存翻页意图，校验轮数后续接；随意刷新默认暂停。关闭标签页结束记录，未完成动作保持未知。
- 记录可导出JSON。不会自动淘汰旧记录；先导出后才提供清理。仍被偏好版本或对照报告引用的源记录保留。浏览器存储用尽时暂停，不静默覆盖。
- 浏览器完全退出或崩溃可能留下未结束会话；可在设置中查看并结束。持续存储故障无法保证最后的事件落盘，界面会显示故障，自动操作停止。

## 费用

决策、偏好归纳和对照回放统一统计。每月累计估算达到 **$5仅提醒，不停止调用、不设置支出上限**。月份按上海时区计算。

Jev默认固定 `jev-1.13.0`，按2026-10-14核实的每百万输入token $0.042、输出免费估算；更换型号时金额记为待核对，避免套用旧价格。归纳模型使用设置中的输入/输出单价。实际用量与采用的价格一并保存；超时、缺失usage或缺少单价不记成免费。金额为估算，最终账单以供应商为准。[Jev接口与价格](https://docs.typesafe.ai/models)

## 验证

```sh
npm run typecheck
npm test
npx playwright install chromium
npm run test:browser
```

单元/集成测试覆盖历史DOM、禁用槽位、怪物效果隔离、陈旧决策、存储失败、未确认响应、会话恢复、费用和示范来源。浏览器测试在临时Chrome配置中加载真实扩展，用本地游戏替身与模拟模型接口跑录制、偏好审阅、接管和跨轮导航；不访问真实游戏账户或付费模型。测试使用本机7001端口。

这些检查验证执行和数据链路，不代表已经测出游戏胜率、偏好理解准确率或真实接口延迟。首次真实使用先录制，审阅记录质量，再用未参与归纳的战斗做对照和小规模接管。

## 代码结构

| 位置 | 职责 |
| --- | --- |
| `src/automation/observe.ts` | 解析当前页面、可用控件与绑定目标的候选，不做模糊名称匹配 |
| `src/automation/engine.ts` | 单动作执行循环、过期结果处理、暂停与恢复 |
| `src/automation/journal.ts` | 事务性事件记录、会话检查点、偏好版本及导出 |
| `src/automation/decision.ts` | Jev协议、费用记录、示范抽样与偏好结果校验 |
| `src/extension/bridge.ts` | 页面侧只观察战斗请求与确认信号，跨世界传递白名单字段 |
| `src/browser/content.ts` | 游戏页操作面板和执行适配 |
| `src/browser/worker.ts` | 扩展后台请求、会话所属校验、归纳和对照任务 |
| `src/extension/options.ts` | 设置、示范选择、偏好审阅及复盘 |

原 `battle-parser`、`command-io`、`prompt-builder` 和实验脚本暂保留为参考资料，新的生产入口不再引用旧聊天决策流水线。原始HTML与Wiki资料继续用于解析验证，不能视作当前游戏规则已全部实测。详细取舍见 [ADR目录](docs/adr) 和 [术语表](GLOSSARY.md)。
